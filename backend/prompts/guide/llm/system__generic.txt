# Purpose: Fallback LLM instruction for system modules without a dedicated prompt file.
# Used by: guide_generation._build_generic_system_prompt (via _resolve_prompt_text).
# Module: system / {system_id} — all SYSTEM_CATALOG ids except overview and engines (which have dedicated files).
# Variables: {system_id}, {icon}, {locs_json}, {focus}, {category_note}, {empty_note}
#
Generate the "{system_id}" system module for a charter vessel guide (Learn + Know tabs).

TARGET: {focus}
{category_note}{empty_note}

Produce id "{system_id}", icon "{icon}", locs {locs_json}.
Include title, subtitle, summary (1-2 sentences), learnChecks (3-5 items), and sections.
Each learn check names gear from the snapshot and an action the guest can do or a place they can find. Do not use "familiarize", "understand", "know how", or "if applicable".
Section types allowed: prose, list, steps, warnings, notes. Do NOT include photo sections — photos are merged from REFERENCE separately.
Prose sections MUST use field "c" for paragraph text (not "text" or "content").

Use ONLY facts from INPUT SNAPSHOT and RELEVANT EQUIPMENT below. Match REFERENCE structure when provided. Do not copy a brochure tone from the reference.

Summary is one factual sentence naming the recorded manufacturer and model (for a tender: "The tender is a Highfield Classic 360."). Omit the summary if no model is recorded.
Do not write a section for gear that is not in the snapshot. If a place, count, or procedure is unknown, omit it. Do not write "not provided", "if applicable", "if fitted", or "familiarize".
Do not use these words: sleek, luxury, experience, versatile.

Reader voice (style — strong preference, not a hard schema rule):
- Establish the boat once by recorded display name from the snapshot.
- After that, prefer direct system/equipment/screen references using "the", or omit any vessel reference.
- Use "she"/"her" only when the boat itself is meaningfully the actor or owner and the pronoun helps clarity.
- Prefer the above over deictics such as "this vessel", "this boat", "this yacht", or bare "the vessel".
- Repeat the vessel name only for disambiguation or a deliberate reorientation.
- Cross-section pointers: "can be found in the <Section> section of this guide" — never "lives in", "stay in", or "home procedures".

Return JSON only — one system object, no wrapper.

# Purpose: LLM instruction for the boat overview system module (layout, day-one orientation).
# Used by: fallback only. system/overview is built by content.assembler.build_overview_module.
# Module: system / overview
# Composed with: guide/schemas/system__overview.txt, INPUT SNAPSHOT, optional REFERENCE MODULE
#
Generate the boat overview system module (Learn the Boat + Know tab).

Use INPUT SNAPSHOT: vessel.name, hull_model.display_name, vessel.vessel_type, equipment list.
Audience: charter guests on day one. Tone: orientation — where things are, layout, safety gear locations.

Reader voice (style — strong preference):
- Establish the boat once by recorded name from the snapshot.
- After that, prefer "the …" / bare facts; use "she"/"her" only when the boat is the actor/owner and clarity needs it.
- Prefer that over "this vessel" / "this boat" / "this yacht".
- Repeat the name only for disambiguation or reorientation.
- Cross-section pointers: "can be found in the <Section> section of this guide" — not "lives in" / "home procedures".

Produce id "overview", icon "🗺️", locs for cockpit/helm/saloon.
Include summary (1-2 sentences), learnChecks (3-5 walkthrough items), and sections.
Each learn check names a recorded place and something the guest can find or do there. Walk recorded places. When the snapshot has separate port and starboard machinery spaces, do not write "the engine room". Do not use "familiarize", "understand", "know how", or "if applicable".
- About [vessel name] (prose) — hull model facts from snapshot only; prose sections MUST use field "c" for paragraph text
- Layout (list) — only places and cabin counts that appear in the snapshot. If a count or a place is missing, omit that line. Do not write "not provided" or any other note that a fact is missing.
- Find These on Day 1 (steps) — only gear whose place is recorded in the snapshot. Omit life jackets, EPIRB, flares, fire extinguishers, fuel fills, and water fills when no location is recorded.

Do not invent cabin counts, layout, or gear locations. Omit the unknown. Do not describe the boat as sleek, luxurious, versatile, or an experience.

Do NOT include sections with type "photo" — deck plan photos are preserved from REFERENCE MODULE separately.
If REFERENCE MODULE is provided, match its section structure and tone; update facts from snapshot.

Return JSON only — one system object, no wrapper.

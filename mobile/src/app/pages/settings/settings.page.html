Signal-K Server
Server URL

Enter your Signal-K server URL (for example https://sailsupernova.com). Cloudflare tunnel URLs are supported and upgraded to a secure WebSocket automatically.

The Sail tab reads live instruments through this connection using the instrument map below. Sign-in passwords are not stored here. Manage the server at its own admin page (e.g. https://your-server/admin), not inside this app.

For local testing, run node generator.js in signalk-sim/ and set the URL to http://localhost:3000. Default scenario sailing streams TWA, TWS, and STW for Polar; use demo for the AIS anchorage.
